# Public ZK DAG

Add an Obsidian-like graph view to the public ZK projection.

MVP:

- Generate `zk/graph.json` from public notes only.
- Include public-to-public edges only.
- Add a simple `/zk/graph.html` page with clickable nodes.
- Link nodes to their UID routes.

Do not expose private-note titles, filenames, or edges.
